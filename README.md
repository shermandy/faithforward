# Faith Forward Ministries Website

A modern, fast, and accessible web application for **Faith Forward Ministries, Inc.**, a volunteer-run 501(c)(3) non-profit organization serving Westmoreland County and surrounding areas. 

Faith Forward Ministries provides compassionate care, counseling, and recovery resources for individuals experiencing homelessness, mental health challenges, or substance use disorders. Core programs include the **Angel Arms Infant and Children Recovery Homes**, **Project Stand**, free faith-based counseling, and community outreach.

---

## 🛠 Tech Stack & Architecture

- **Static Site Generator:** [Eleventy (11ty)](https://www.11ty.dev/)
- **Content Management System:** [Decap CMS](https://decapcms.org/) (Decoupled Git-based CMS)
- **Templating Engine:** Nunjucks (`.njk`)
- **Styling:** Custom CSS Flexbox architecture
- **Hosting & Deployment:** [Cloudflare Pages](https://pages.cloudflare.com/)

---

## 🚀 Key Features & Components

### 1. Modular Page Builder (`blocks`)
Pages are built dynamically using custom, re-orderable content blocks configured in Decap CMS:
- **Hero Banner:** Full-width header section with background images, rich text, and primary/secondary button calls-to-action.
- **Media Box (Image & Content Box):** Configurable side-by-side layout supporting left/right image orientation, custom background color themes (**White**, **Light Grey**, **Amber**, **Dark Green**), heading, rich content, and styled action buttons (Primary, Secondary, Tertiary).
- **Rich Text & Multi-Text Grids:** Multi-column text sections for flexible content presentation.
- **Image Card Grids & Three-Card Sections:** Hover-zoom interactive cards designed for highlights, core initiatives, and navigation hubs.

### 2. Events System
- Single event templates powered by `event.njk` layout wrappers and `events.json` directory settings.
- Dynamic calendar integration providing direct **Add to Google Calendar** and **Download iCal (.ics)** action buttons.
- Stretched-link interactive event cards with date filters and location metadata.

### 3. Decap CMS Admin Integration
- Custom live previews for pages (`PagePreview`) and events (`EventPreview`) in `admin/index.html`.
- Custom shortcode editor components registered for inline rich-text enhancements (e.g., Alert Boxes and Styled Button Links).

## 📁 Key Directory Structure

```text
├── admin/
│   ├── config.yml          # Decap CMS collection & block definitions
│   └── index.html          # CMS entry point & live preview templates
├── css/
│   └── style.css           # Global stylesheet & modular layout utilities
├── events/
│   ├── events.json         # Directory data file establishing layout inheritance
│   └── *.md                # Individual event content files
├── _includes/
│   ├── layout.njk          # Primary site layout template
│   └── event.njk           # Layout template for individual event detail pages
├── _site/                  # Compiled output directory generated by Eleventy
├── .eleventy.js            # Eleventy build configuration & custom filters
└── README.md               # Project documentation
```

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- Git

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npx @11ty/eleventy --serve
   ```

4. Open `http://localhost:8080` in your browser to view the site.
5. Access `http://localhost:8080/admin/` to work with the CMS locally using Decap's local backend mode if configured.

---

## ☁️ Deployment

This repository is optimized for deployment on **Cloudflare Pages**:

1. Connect your GitHub repository to Cloudflare Pages.
2. Configure build settings:
   - **Framework preset:** `None` (or `Eleventy`)
   - **Build command:** `npx @11ty/eleventy`
   - **Build output directory:** `_site`
3. Ensure the main repository branch is set to trigger automatic builds on updates.
